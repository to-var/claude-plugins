# Generic spinner verbs

Style seed for a theme's `verbs`. Offer a few of these as examples when the user
picks verbs, then write themed ones. All are "-ing" phrases of at most 30 characters.

Connecting the dots, Sorting things out, Digging deeper, Following the trail,
Gathering clues, Drafting a plan, Testing an idea, Fixing the details,
Polishing the result, Counting the steps, Packing the bags, Tuning the engine,
Looking closer, Making a list, Asking around, Studying the case, Sharpening the tools,
Reading the signs, Mixing it up, Setting the stage, Lining things up,
Running the numbers, Weighing the options, Crossing the bridge, Cleaning up,
Taking notes, Charting a course, Spinning up, Piecing it together,
Taking a closer look, Working on it, Chasing a hunch, Opening the toolbox,
Getting ready, Turning the page, Solving the puzzle, Stacking the pieces,
Adjusting the dials
