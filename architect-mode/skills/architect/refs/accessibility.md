# accessibility: UI access for all users

- Use native elements before custom ones.
- Every control works with the keyboard and shows focus.
- Inputs have labels. Images have alt text or are marked decorative.
- Headings and landmarks follow page structure.
- Text and controls meet WCAG AA contrast.
- Meaning does not depend on color alone.
- Dialogs take focus, keep it and give it back.
- Screen readers hear dynamic updates.
- Motion respects the reduced motion setting.
- Layout works at 200% zoom and on small screens.
