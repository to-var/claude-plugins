# Changelog

## 0.3.0 (2026-11-28)

- A notes pane with decisions, patterns and file tree ideas, each with sources, and `/architect-notes`.
- Questions typed in the pane are answered by a copy of the chat.
- A notes log per project in the plugin data folder.

## 0.2.0 (2026-11-28)

- Renamed from `tovarchitect` to `architect-mode`. The command is now `/architect-mode:architect`.
- Moved into the `tovar` marketplace, in `to-var/claude-plugins`.
- The plugin data folder changes with the name. Saved backlogs and framework rules do not move by themselves.

## 0.1.0 (2026-11-27)

- A lead and an expert panel with `ok`, `change` and `block` verdicts.
- An edit lock with `strict` and `warn` modes, and `/architect-off`.
- An offer of architect mode on new code tasks, a status line and `/architect-status`.
- Refactor and audit runs with a project backlog.
- A framework expert and a librarian with a short rule index.
